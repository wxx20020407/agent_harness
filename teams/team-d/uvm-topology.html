UVM Testbench Topology

Universal Verification Methodology Architecture

Test Hierarchy

  • • uvm_test: Top-level test case
  • • uvm_env: Encapsulates verification env
  • • uvm_agent: Bundles driver/monitor/sequencer
  • • Hierarchical build_phase construction

Agent Components

  • • Sequencer: Generates transaction items
  • • Driver: Drives signals to DUT
  • • Monitor: Observes DUT activity
  • • Active/Passive mode configuration

Analysis & Coverage

  • • Scoreboard: Compares expected vs actual
  • • Coverage: Collects functional coverage
  • • Analysis ports: TLM communication
  • • connect_phase: Establish TLM connections

UVM Testbench Architecture • IEEE 1800.2 Standard • Phases: build → connect → run
